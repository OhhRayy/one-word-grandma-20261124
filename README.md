## What it does

`main.py` writes exactly one word to `/output/entry.txt`: the word grandma would text about AI. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The word:

> witchcraft

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
